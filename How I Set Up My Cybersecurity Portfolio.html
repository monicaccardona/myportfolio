How I Set Up My Cybersecurity Portfolio

Creating my cybersecurity portfolio was an exciting step toward building my professional identity for my future career opportunities. I started by purchasing a personal domain, mcardonacyber.my, through Porkbun. Having a custom domain gave me the freedom to showcase my skills on my terms and stand out in a competitive industry.

Next, I set up a branded email address using Zoho Mail, monicacardona@mcardonacyber.my , to give my communication a polished and professional feel. From there, I created a GitHub repository where I built a simple homepage using HTML. This portfolio includes my bio, contact info, and links to my GitHub and LinkedIn profiles.

I hosted my site using GitHub Pages and connected it to my custom domain through DNS settings in Porkbun. Although troubleshooting DNS and HTTPS took a little patience, I learned how domain records, CNAMEs, and A records work, these are valuable skills for anyone in cybersecurity.

This experience gave me hands-on exposure to web hosting, DNS management, and professional branding, all while showcasing my growing technical skills. It also taught me how important it is to maintain a consistent and secure online presence, especially in cybersecurity where attention to detail matters.
